# 💰 FinTrack – Smart Expense Management System

A full-stack personal finance app built with the **MERN stack** that helps you track expenses, manage budgets, monitor recurring transactions, and receive **AI-powered spending insights** — all in one clean dashboard.

##  Features

- 🔐 **JWT Authentication** – Secure register/login with password hashing
- 💸 **Expense Tracking** – Add, edit, delete, and filter expenses by category/date
- 📊 **Analytics Dashboard** – Interactive pie & bar charts (Recharts)
- 🎯 **Budget Management** – Set monthly budgets per category with progress tracking
- 🤖 **AI Spending Insights** – Personalized saving tips powered by OpenAI
- 📱 **Responsive UI** – Tailwind CSS with mobile-friendly layout

---

## 🛠️ Tech Stack

| Layer | Technologies |
|-------|-------------|
| **Frontend** | React (Vite), Tailwind CSS, React Router, React Query, Recharts, Axios |
| **Backend** | Node.js, Express.js, MongoDB (Mongoose), JWT, bcrypt, node-cron |
| **AI** | OpenAI API (gpt-4o-mini) |
| **Deployment** | Vercel (frontend), Render (backend), MongoDB Atlas |
